# 🎙️ Локальна Голосова Помічниця (AI VTuber Core)

Проєкт локальної цифрової асистентки з інтелектуальною активацією на голос (**VAD**), розпізнаванням мовлення (**STT**), локальним штучним інтелектом (**LLM**) та реалістичним синтезом українського голосу (**TTS**). Повністю оптимізований для стабільної роботи на CPU без використання відеокарти.

Проєкт має модульну структуру і підготовлений для подальшої передачі LipSync-тексту та емоцій на 3D VRM моделі (Unity, VSeeFace, веб-аватари тощо).

---

## 💻 Системні вимоги
* **Процесор (CPU):** Intel(R) Core(TM) i5-8265U @ 1.60GHz (4 ядра / 8 потоків). Налаштовано використання **4 потоків** для LLM, а для потоків `PyTorch` та `Intel MKL` встановлено ліміти, що запобігає крашу Windows `Access Violation (0xC0000005)`.
* **Оперативна пам'ять (RAM):** 12,0 ГБ (загальне споживання ОЗП усім ШІ-комплексом разом із моделлю голосу та вербалізатором чисел становить ~7-8 ГБ).
* **Відеокарта (GPU):** Інтегрована Intel UHD Graphics 620 (всі обчислення переведені на CPU, GPU не навантажується).

## 📂 Структура проєкту

```text
AI_VTUBER/
│
├── .venv/                  # Віртуальне оточення Python (3.11)
├── bin/                    # Бінарні файли FFmpeg (ffmpeg.exe, ffprobe.exe) для pydub
├── models/                 # Важкі ШІ-моделі (ігноруються Git)
│   ├── Gemma-4-E4B-Uncensored-HauhauCS-Aggressive-Q4_K_M.gguf   # Логіка (LLM)
│   ├── styletts2_ukrainian_multispeaker/                       # Голос (StyleTTS2)
│   └── mbart-large-50-verbalization/                            # Числа (mBART)
│
├── input/                  # Тека для вхідних аудіофайлів з мікрофона
│   └── temp_voice.wav      # Тимчасовий файл запису вашого голосу
│
├── outputs/                # Тека збереження згенерованих відповідей помічниці (.wav, .mp3)
├── references/             # Референсні аудіофайли .wav для динамічного клонування
├── voices/                 # Клоновані пресети голосів (.pt)
│   └── Інна Гелевера.pt
│
├── audio_handler.py        # Модуль розпізнавання голосу (Whisper small з анти-галюцинацією)
├── llm_handler.py          # Модуль мислення та характеру (Gemma через llama.cpp без C++ спаму)
├── tts_handler.py          # Повноцінний ШІ-синтез голосу StyleTTS2 UA + mBART + текстові фільтри
├── main.py                 # Центральний оркестратор (двохетапний запис мікрофона та патчі пам'яті)
├── download_models.py      # Скрипт для автоматичного завантаження моделей голосу з HuggingFace
├── config.json             # Конфігурація системи, чутливості мікрофона та промпту характеру
└── requirements.txt        # Список залежностей проєкту (індекс CPU Torch)

```

## ⚙️ Налаштування та запуск

### 1. Створення віртуального оточення та встановлення залежностей

Проєкт розроблено та оптимізовано під **Python 3.11**. Відкрийте термінал (PowerShell або CMD) у корені папки проєкту та виконайте:

```bash
# 1. Перевірте версію Python (має бути 3.11.x)
python --version

# 2. Створіть чисте віртуальне оточення .venv
python -m venv .venv

# 3. Активуйте створене віртуальне оточення
# Для PowerShell:
.\.venv\Scripts\Activate.ps1
# Для звичайного CMD:
.\.venv\Scripts\activate.bat

# 4. Оновіть pip
python -m pip install --upgrade pip

# 5. Встановіть бібліотеки (включаючи CPU-версію PyTorch та українські лінгвістичні пакети)
pip install -r requirements.txt

```

### 2. Завантаження ШІ-моделей

1. Покладіть файл моделі мислення `Gemma-4-E4B-Uncensored-HauhauCS-Aggressive-Q4_K_M.gguf` у створену папку `models/`.
2. Запустіть скрипт для автоматичного скачування ваг українського голосу StyleTTS2 та лінгвістичного вербалізатора чисел mBART:
```bash
python download_models.py

```



### 3. Налаштування FFmpeg

Переконайтеся, що у корені проєкту є папка `bin/`, де лежать `ffmpeg.exe` та `ffprobe.exe`. Модуль `tts_handler.py` автоматично підтягне їх у системні шляхи (PATH) під час запуску для генерації MP3-файлів.

### 4. Запуск помічниці

```bash
python main.py

```

## 🛠️ Як це працює (Логіка циклу та фільтрації)

1. **Розумне очікування (Двохетапний VAD):** Програма не записує тишу. Вона перебуває в стані моніторингу фону, доки RMS гучність мікрофона не перевищить ліміт `threshold` з файлу `config.json` (рекомендовано `0.02` або `0.03`).
2. **Запис фрази:** Як тільки ти починаєш говорити, тригер перемикається в стан активного запису. Після завершення мовлення система чекає `1.2` секунди тиші й автоматично зупиняє запис (`🤫 Пауза зафіксована`).
3. **Чисте розпізнавання (STT):** Whisper транскрайбить голос у текст українською мовою. Завдяки прапорцю `condition_on_previous_text=False`, модель повністю застрахована від галюцинацій та повторення фраз на коротких аудіо фрагментах.
4. **Формування думки (LLM):** Текст передається в модель Gemma. Вивід логів C++ бібліотеки `llama.cpp` повністю перенаправляється в `os.devnull`, забезпечуючи абсолютно чистий лог діалогу у консолі.
5. **Фільтрація тексту та Синтез (TTS):** * Перед відправкою відповіді у StyleTTS2, текст проходить очищення регулярними виразами: видаляються всі емодзі (`😉`, `😊`), трикрапки замінюються на крапку, а подвійні пробіли забираються. Це на 100% захищає PyTorch від падіння через генерацію `0-dim` (порожніх) тензорів.
* Числа автоматично переводяться в слова за допомогою mBART/num2words, текст розставляє наголоси через `ukrainian-word-stress` та озвучується відповідно до налаштувань конфігу.



### 🎛️ Повне пояснення параметрів TTS у `config.json`:

* **`mode`** *(string, дефолт: "1")* Режим роботи синтезу мовлення:
* `"1"` — Режим пресету: використовує готовий зліпок голосу у форматі `.pt`.
* `"2"` — Режим клонування: миттєво копіює голос із короткого аудіофайлу `.wav`.


* **`preset_filename`** *(string, дефолт: "Інна Гелевера.pt")* Ім'я файлу готового голосу, який лежить у папці `voices/`. Використовується лише якщо параметр `mode` виставлено в `"1"`.
* **`reference_filename`** *(string, дефолт: "sample.wav")* Ім'я аудіофайлу-донора з папки `references/`, чий голос буде скопійовано. Використовується лише якщо параметр `mode` виставлено в `"2"`.
* **`speed`** *(float, дефолт: 1.0)* Базова швидкість вимови тексту. `1.0` — стандартний темп, `0.9` — трохи повільніше, `1.1` — швидше.
* **`noise_scale`** *(float, дефолт: 0.1)* Рівень ШІ-варіативності інтонацій. Значення `0.0` робить голос стабільним, але монотонним, а `0.1`–`0.2` додає живої, природної експресії.
* **`match_duration`** *(boolean, дефолт: false)* Автоматичне підлаштування темпу мовлення (`true` / `false`). Якщо увімкнено, ШІ намагатиметься вимовити новий текст із тією ж швидкістю та таймінгами, що й оригінальний файл-референс (працює тільки для `mode: "2"`).
* **`use_verbalizer`** *(boolean, дефолт: true)* Активація мовної підсистеми (`true` / `false`). Якщо вибрано `true`, задіюється важка нейромережа mBART для інтелектуального читання чисел з урахуванням контексту. Якщо `false` — її буде вимкнено для заощадження ~2 ГБ оперативної пам'яті (увімкнеться швидка алгоритмічна заміна).

## 🔗 Використані ШІ-технології та Джерела

Цей проєкт став можливим завдяки поєднанню передових open-source інструментів, адаптованих під українську мову:

### 🎙️ Розпізнавання мовлення (STT)

* **[Faster-Whisper](https://github.com/SYSTRAN/faster-whisper)** — оптимізована реалізація моделі Whisper від OpenAI за допомогою двигуна `CTranslate2`, яка працює в рази швидше за оригінал на CPU.
* **[Whisper Small Model](https://huggingface.co/Systran/faster-whisper-small)** — ваги ШІ-моделі для розпізнавання тексту.

### 🧠 Модель мислення (LLM)

* **[Llama.cpp Python](https://github.com/abetlen/llama-cpp-python)** — Python-бібліотека для запуску квантованих моделей у форматі `.gguf` з максимальною оптимизацією під процесори (AVX2/AVX512).
* **[Gemma-4-E4B-Uncensored-HauhauCS-Aggressive](https://huggingface.co/HauhauCS/Gemma-4-E4B-Uncensored-HauhauCS-Aggressive)** — кастомна текстова модель на базі архітектури **Gemma**, дотренована для емоційних, зухвалих та нефільтрованих відповідей (Uncensored). Саме вона забезпечує той самий фірмовий сарказм та характер нашої Помічниці.

### 🔊 Синтез українського голосу (TTS)

* **[StyleTTS2 Inference UA](https://github.com/patriotyk/styletts2-inference)** — адаптований інференс топової моделі синтезу мовлення під українську мову (розробник: `@patriotyk`).
* **[StyleTTS2 Ukrainian Extended UI](https://huggingface.co/spaces/Veymo/styletts2-ukrainian-extendedUI)** — розширений веб-інтерфейс на HuggingFace Spaces для зручного тестування, генерації пресетів голосу та тонкого налаштування параметрів мовлення.
* **[Ukrainian Word Stress](https://www.google.com/search?q=https://github.com/patriotyk/ukrainian-word-stress)** — автоматичний словник та алгоритм розстановки правильних наголосів в українських словах.
* **[IPA UK](https://www.google.com/search?q=https://github.com/patriotyk/ipa-uk)** — конвертер українського тексту у міжнародний фонетичний алфавіт (IPA) для правильної вимови.
* **[mBART Large 50 Verbalization](https://huggingface.co/skypro1111/mbart-large-50-verbalization)** — лінгвістична модель від Meta (`mbart-large-50`), дотренована для перетворення цифр та абревіатур на правильні за відмінками українські слова.

### 🎛️ Аудіо-двигуни

* **[SoundDevice](https://python-sounddevice.readthedocs.io/)** — бібліотека для низькорівневого перехоплення аудіопотоку з мікрофона в реальному часі.
* **[FFmpeg](https://ffmpeg.org/)** — універсальний медіа-конвертер, який використовується проєктом для стиснення та фінального збереження голосу в формат MP3.
