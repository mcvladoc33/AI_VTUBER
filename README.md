# 🎙️ Локальна Голосова Помічниця (AI VTuber Core)

Проєкт локальної цифрової асистентки з інтелектуальною активацією на голос (**VAD**), розпізнаванням мовлення (**STT**), локальним штучним інтелектом (**LLM**) та реалістичним синтезом українського голосу (**TTS**). Повністю оптимізований для стабільної та максимально швидкої роботи на CPU без використання відеокарти.

Проєкт має модульну структуру і підготовлений для подальшої передачі LipSync-тексту та емоцій на 3D VRM моделі (Unity, VSeeFace, веб-аватари тощо).

---

## 💻 Системні вимоги
* **Процесор (CPU):** Intel(R) Core(TM) i5-8265U @ 1.60GHz (4 ядра / 8 потоків). Налаштовано використання **4 потоків** для LLM, а для потоків `PyTorch` та `Intel MKL` встановлено ліміти, що запобігає крашу Windows `Access Violation (0xC0000005)`.
* **Оперативна пам'ять (RAM):** 12,0 ГБ (загальне споживання ОЗП усім ШІ-комплексом разом із моделлю голосу та вербалізатором чисел становить ~7-8 ГБ).
* **Відеокарта (GPU):** Інтегрована Intel UHD Graphics 620 (всі обчислення переведені на CPU, GPU не навантажується).

## ⚙️ Налаштування та запуск

### 1. Створення віртуального оточення та встановлення залежностей

Проєкт розроблено та оптимізовано під **Python 3.11**. Відкрийте термінал (PowerShell або CMD) у корені папки проєкту та виконайте:

```bash
# 1. Перевірте версію Python (має бути 3.11.x)
python --version

# 2. Створіть чисте віртуальне оточення .venv
python -m venv .venv

# 3. Активуйте створене віртуальне оточення
# Для PowerShell:
.\.venv\Scripts\Activate.ps1
# Для звичайного CMD:
.\.venv\Scripts\activate.bat

# 4. Оновіть pip
python -m pip install --upgrade pip

# 5. Встановіть бібліотеки (включаючи CPU-версію PyTorch та українські лінгвістичні пакети)
pip install -r requirements.txt

```

### 2. Завантаження ШІ-моделей

1. Покладіть файл моделі мислення `Gemma-4-E4B-Uncensored-HauhauCS-Aggressive-Q4_K_M.gguf` у створену папку `models/`.
2. Запустіть скрипт для автоматичного скачування ваг українського голосу StyleTTS2 та лінгвістичного вербалізатора чисел mBART:

```bash
python download_models.py

```

### 3. Налаштування FFmpeg

Переконайтеся, що у корені проєкту є папка `bin/`, де лежать `ffmpeg.exe` та `ffprobe.exe`. Модуль `tts_handler.py` автоматично підтягне їх у системні шляхи (PATH) під час запуска для генерації та безшовного склеювання MP3-файлів.

### 4. Запуск помічниці

```bash
python main.py

```

## 🛠️ Як це працює (Логіка циклу та архітектурні режими)

Проєкт підтримує два фундаментальні режими роботи, які керуються через конфігураційний файл, що виключає системні дедлоки, блокування консолі та конфлікти звукового заліза Windows:

1. **Голосовий режим (`"text_mode": false`):**
* **Розумне очікування (VAD):** Програма не записує тишу. Вона перебуває в стані моніторингу фону, доки RMS гучність мікрофона не перевищить ліміт `threshold` (рекомендовано `0.05`).
* **Запис фрази:** Як тільки ви починаєте говорити, тригер перемикається в стан активного запису. Після завершення мовлення система чекає `1.2` секунди тиші й автоматично зупиняє процес.
* **Чисте розпізнавання (STT):** Whisper транскрайбить голос у текст. Завдяки прапорцю `condition_on_previous_text=False`, модель повністю застрахована від галюцинацій та повторення фраз на коротких або зашумлених аудіофрагментах.


2. **Текстовий режим (`"text_mode": true`):**
* Система повністю вимикає низькорівневі потоки аудіозапису, захищаючи Whisper від збору сторонніх шумів (стукіт клавіатури, зітхання).
* Взаємодія переходить на нативний, прозорий синхронний ввід Python (`input()`). Ви бачите кожну літеру під час друку, можете редагувати текст за допомогою клавіші `Backspace` і відправляти повідомлення кнопкою `Enter`.


3. **Формування думки (LLM):** Текст передається в модель Gemma. Вивід логів C++ бібліотеки `llama.cpp` повністю перенаправляється в `os.devnull`, забезпечуючи абсолютно чистий лог діалогу у консолі. Промпт налаштований на лаконічні та іронічні репліки.
4. **Інтелектуальна нарізка тексту та Синтез (TTS):**
* **Гіпершвидкість на CPU:** Кроки дифузії моделі StyleTTS2 апаратно зменшено з 5 до **3 ступенів**, що дозволило скоротити час генерації аудіо майже вдвічі без втрати якості мовлення.
* **Захист від заїкань:** Скрипт динамічно ріже довгі речення на оптимальні для обробки CPU шматки (до 60 символів). Процес нарізки використовує регулярні вирази з негативним переглядом вперед, повністю **ігноруючи розділові знаки всередині лапок** (`""` або `«»`). Це гарантує, що пряма мова чи цитати будуть вимовлені суцільним емоційним блоком, без розривів та паузи посеред слова.
* **Бронебійна страховка:** Якщо модель видає довгий монолітний текст без жодної коми, алгоритм акуратно розбиває його по пробілах між словами, запобігаючи перевантаженню процесора.
* **Безшовне склеювання:** Перший готовий шматочок аудіо моментально передається в плеєр і починає звучати, а всі наступні фрагменти паралельно дорендерюються і безшовно дошиваються у хвіст файлу `output.mp3`. Головний цикл оркестратора надійно очікує завершення відтворення репліки (`tts_module.wait_until_done()`), перед тим як перейти на нове коло очікування.

## 🎛️ Параметри конфігурації (`config.json`)

Анатомія файлу конфігурації для гнучкого налаштування поведінки ШІ-комплексу:

```json
{
  "stt": {
    "model_size": "small",
    "device": "cpu",
    "compute_type": "int8"
  },
  "llm": {
    "model_path": "models/Gemma-4-E4B-Uncensored-HauhauCS-Aggressive-Q4_K_M.gguf",
    "n_ctx": 1024,
    "max_tokens": 180,
    "temperature": 0.65,
    "n_threads": 4,
    "n_batch": 16
  },
  "tts": {
    "mode": "1",
    "preset_filename": "Інна Гелевера.pt",
    "reference_filename": "sample.wav",
    "speed": 1.25,
    "noise_scale": 0.05,
    "match_duration": false,
    "use_verbalizer": false
  },
  "character": {
    "name": "Селті",
    "system_prompt": "Ти — зухвала та іронічна цифрова асистентка Селті. Твоє завдання — відповідати лаконічно, ємно та саркастично розмовною українською мовою. Твоя відповідь має складатися строго з 2-3 коротких речень. Якщо у тебе просять рецепт чи інструкцію — спершу уїдливо підколи, а потім одразу накидай саму суть (перелік інгредієнтів чи дій) дуже стисло, в одне речення. Пиши виключно звичайним текстом без маркдауну, лапок, дужок чи приміток."
  },
  "text_mode": false
}

```

### Детальний опис ключів управління:

* **`text_mode`** *(boolean)* — Головний перемикач інтерфейсу:
* `false` — Активовано режим мікрофона з інтелектуальним VAD-записом.
* `true` — Активовано текстовий чат через консольний `input()` (ідеально для нічних тестів без використання голосу).


* **`stt.compute_type`** *(string)* — Оптимізація моделі розпізнавання. Виставлено в `"int8"` для максимального стиснення ваг та прискорення STT на процесорах споживчого класу.
* **`llm.n_threads`** *(integer)* — Кількість ядер процесора, виділених під розрахунки нейромережі. Строго обмежено до `4` для стабільності на архітектурах ноутбуків.
* **`tts.mode`** *(string)* — Режим генерації мовлення:
* `"1"` — Використовує готовий зліпок голосу з папки `voices/`.
* `"2"` — Вмикає динамічне клонування в реальному часі на основі донора з теки `references/`.


* **`tts.preset_filename`** *(string)* — Файл активованого голосу (наприклад, пресет `"Інна Гелевера.pt"`).
* **`tts.speed`** *(float)* — Темп мовлення. Оптимально виставлено на `1.25` для жвавого, реалістичного та таймінгово збалансованого розмовного потоку на стрімах.
* **`tts.noise_scale`** *(float)* — Рівень варіативності інтонацій моделі StyleTTS2. Значення `0.05` забезпечує ідеальну стабільність дикції на CPU без появи роботизованих артефактів.
* **`tts.use_verbalizer`** *(boolean)* — Якщо `false`, важка нейромережа mBART відключається, вивільняючи ~2 ГБ RAM. Числа конвертуються в слова за допомогою миттєвого алгоритмічного модуля `num2words`.
* **`character.system_prompt`** *(string)* — Ядро особистості та поведінковий фільтр. Задає характер, саркастичний тон, мовні обмеження та інструкції щодо жорсткого лімітування довжини відповідей.

## 🔗 Використані ШІ-технології та Джерела

* **[Faster-Whisper](https://github.com/SYSTRAN/faster-whisper)** — оптимізована реалізація моделі Whisper за допомогою двигуна `CTranslate2`.
* **[Llama.cpp Python](https://github.com/abetlen/llama-cpp-python)** — Python-бібліотека для запуска квантованих моделей у форматі `.gguf`.
* **[Gemma-4-E4B-Uncensored-HauhauCS-Aggressive](https://huggingface.co/HauhauCS/Gemma-4-E4B-Uncensored-HauhauCS-Aggressive)** — кастомна текстова модель на базі архітектури **Gemma**, дотренована для емоційних та саркастичних відповідей.
* **[StyleTTS2 Inference UA](https://github.com/patriotyk/styletts2-inference)** — адаптований інференс топової моделі синтезу мовлення під українську мову (розробник: `@patriotyk`).
* **[Ukrainian Word Stress](https://www.google.com/search?q=https://github.com/patriotyk/ukrainian-word-stress)** — автоматичний словник та алгоритм розстановки правильних наголосів.
* **[IPA UK](https://www.google.com/search?q=https://github.com/patriotyk/ipa-uk)** — конвертер українського тексту у міжнародний фонетичний алфавіт (IPA).
* **[mBART Large 50 Verbalization](https://huggingface.co/skypro1111/mbart-large-50-verbalization)** — модель від Meta для інтелектуального читання чисел.
* **[SoundDevice](https://python-sounddevice.readthedocs.io/)** — бібліотека для низькорівневого перехоплення аудіопотоку з мікрофона.
* **[FFmpeg](https://ffmpeg.org/)** — універсальний медіа-конвертер для зшивання звукових доріжок.
