# 🎙️ Локальна Голосова Помічниця (AI VTuber Core)

Проєкт локальної цифрової асистентки з активацією на голос (**VAD**), розпізнаванням мовлення (**STT**) та локальним штучним інтелектом (**LLM**), оптимізований для роботи на CPU (без потужної відеокарти). 

Проєкт має модульну структуру, розроблену спеціально для подальшої інтеграції з 3D VRM моделями (Unity, VSeeFace, веб-аватари тощо).

---

## 💻 Системні вимоги (Оптимізовано під твій ПК)
* **Процесор (CPU):** Intel(R) Core(TM) i5-8265U @ 1.60GHz (4 ядра / 8 потоків) — налаштовано використання **4 потоків** для LLM.
* **Оперативна пам'ять (RAM):** 12,0 ГБ (моделі завантажуються паралельно, споживання ОЗП ~6-8 ГБ).
* **Відеокарта (GPU):** Інтегрована Intel UHD Graphics 620 (всі обчислення переведені на CPU, GPU не навантажується).

## 📂 Структура проєкту

```text
AI_VTUBER/
│
├── .venv/                  # Віртуальне оточення Python

├── audio_handler.py        # Модуль розпізнавання голосу (Whisper small + VAD)
```

## ⚙️ Налаштування та запуск

### 1. Створення віртуального оточення (.venv) та встановлення залежностей

Проєкт протестовано та оптимізовано під **Python 3.11**. Використання саме цієї версії гарантує коректну компіляцію бібліотеки `llama-cpp-python` на Windows без додаткових налаштувань С++ компіляторів.

Переконайтеся, що ви знаходитесь у папці проєкту `D:\python_project\AI_VTUBER\`, відкрийте термінал (PowerShell або CMD) та виконайте:

```bash
# 1. Перевірте версію Python (має бути 3.11.x)
python --version

# 2. Створіть чисте віртуальне оточення з назвою .venv
python -m venv .venv

# 3. Активуйте створене віртуальне оточення
# Для PowerShell:
.\.venv\Scripts\Activate.ps1
# Для звичайного CMD:
.\.venv\Scripts\activate.bat

# 4. Оновіть базовий менеджер пакетів pip
python -m pip install --upgrade pip

# 5. Встановіть усі необхідні бібліотеки
pip install -r requirements.txt

```

*Примітка:* Якщо після активації в терміналі зліва від рядка з'явився напис `(.venv)`, значить усе зроблено правильно.

### 2. Завантаження LLM моделі

Створіть папку `models/` у корені проєкту та покладіть туди вашу модель у форматі `.gguf`:
`Gemma-4-E4B-Uncensored-HauhauCS-Aggressive-Q4_K_M.gguf`

### 3. Запуск помічниці

```bash
python main.py

```

При першому запуску модуль `audio_handler.py` автоматично завантажить модель розпізнавання мовлення **Whisper `small**` (~460 МБ) у системний кеш. Наступні запуски відбуватимуться миттєво.

## 🛠️ Як це працює (Логіка циклу)

1. **Постійне слухання фону:** Програма аналізує RMS гучність мікрофона. Коли рівень перевищує ліміт (`threshold`), вмикається запис.
2. **Пре-рол та розумна пауза:** Система зберігає 1.5 секунди фону до початку мовлення (щоб не ковтати перші літери) і чекає 1.2 секунди тиші після завершення вашої фрази, щоб зупинити запис.
3. **Чищення та Точність (STT):** Текст розпізнається через Whisper з акцентом на українську мову (`initial_prompt`) та фільтрацією шумів ноутбука (`vad_filter=True`).
4. **Генерація відповіді (LLM):** Текст передається в Gemma. Відповідь обмежена до 60 токенів (1-3 речення), що дозволяє низьковольтному процесору i5 генерувати репліки за лічені секунди.
